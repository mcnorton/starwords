# STAR WORDS: Breakthrough

**Episode 1** — 포위를 뚫고 탈출하라.

광활한 우주 배경 전투와 타자 연습을 결합한 웹기반 게임입니다. 적 함선의 이름을 빠르게 입력하여 조준하면, 사격통제 컴퓨터가 강력한 포톤빔을 발사합니다. 운석지대를 통과하고 적 함대의 엄청난 규모의 포위망을 돌파해 무사히 탈출하세요.

> 스타워즈 영화 시리즈처럼, 부제 **Breakthrough**는 시즌 스토리와 연결됩니다. Episode 1의 배경은 침략군의 포위를 뚫고 탈출하는 작전입니다. 15회의 전투를 마치면 성공적인 **Breakthrough!** 엔딩으로 마무리 됩니다.

## 1. 특징

- **우주 슈팅 + 타자 연습** — 재미있는 슈팅 게임과 타자 연습을 결합하여 즐겁게 학습할 수 있습니다.
- **초등 필수어휘** — 한글은 초등학교 학년별 필수어휘, 영어는 수준별로 분류된 1~10 단계 어휘로 출제됩니다. 챌린지가 오를수록 단어가 누적되어 점점 어려워집니다.
- **4종 적 함선** — 빠른 근접전투기, 구축함, 순양함, 강력한 레이저빔 전함이 각각 다른 공격 무기를 사용합니다.
- **ENERGY SHIELD** — 적의 공격무기(미사일, 레이저빔)에 피격되면 실드가 감소합니다. 0이 되면 함선이 파괴되고 게임이 끝납니다.
- **POWER BEAM** — 적을 명중할 때마다 모든 포를 동시에 발사할 수 있는 융함로가 충전(+10%)되며, 100% 충전 되면 전포발사 코드(속담, 관용구)를 입력해 화면의 모든 적을 한 번에 격추할 수 있습니다.
- **회피 조작** — 화살표 키(↑/↓)로 함선을 이동해 미사일을 피할 수 있습니다.
- **TRIGGERING SKILL** — 타이핑 속도(타/분)를 정확한 알고리즘으로 실시간 측정합니다. 게임 오버 시 스킬 보너스가 최종 점수에 반영됩니다.
- **MISSION POINTS & TOP 10** — 격추 성과와 전포 발사로 점수를 획득하고, 로컬 저장소에 TOP 10 기록이 남습니다.
- **한글/영어 지원** — 콜사인(이름), 통신 언어(한글·English)를 선택합니다. 한글은 초등학교 학년(Grade) 수준을 선택할 수 있습니다.
- **일시정지** — 다른 창을 활성화하거나 작업을 전환하면 게임이 자동으로 일시정지됩니다. 다시 돌아와 이어서 진행할 수 있습니다.

## 3. INSTALL (+오프라인 플레이)

**태블릿·PC에 앱으로 설치하면 네트워크 없이도 플레이할 수 있습니다.**

1. **[starwords.vercel.app](https://starwords.vercel.app/)** 접속
2. 설정 **⚙** → 하단 [**INSTALL]버튼 실행**
3. 브라우저 설치 확인창에서 [**Install]버튼 확인**


| 환경                                                   | 설치 방법                 |
| ---------------------------------------------------- | --------------------- |
| **데스크탑(Win/Mac) Chrome, Edge / 태블릿(Android) Chrome** | 설정창의 **[INSTALL]** 버튼 |
| **Apple iPad / iPhone Safari**                       | 공유 → **홈 화면에 추가**     |


- 설치가 끝나면 버튼이 **INSTALLED**로 바뀌고, 바탕화면, 홈화면·앱 목록의 **"STAR WORDS"** 아이콘으로 실행합니다.
- 한 번 온라인으로 설치한 뒤에는 **오프라인** 플레이가 가능합니다.

## 4. 게임진행방법



### 시작하기

1. 타이틀 화면에서 **[ENTER]** 키를 누르거나 화면을 클릭합니다.
2. **"Ready for Battle"** 설정창에서 콜사인(Callsign) 이름과 타자연습 언어를 설정한 뒤 **[Deploy]**버튼을 누릅니다.
  - [한글] 언어가 선택되면 **Grade(1~6학년)** 항목이 나타나며, 선택된 학년 수준의 필수어휘가 출제됩니다.
  - [English]를 선택하면 Grade 구분없이 1~10 레벨의 초등 필수어휘가 출제됩니다.
3. **3 → 2 → 1** 카운트다운 후 **CHALLENGE 1**이 시작됩니다.



### 기본 조작


| 입력                 | 동작                    |
| ------------------ | --------------------- |
| 단어 입력 + **ENTER**  | 적 함선 위 단어와 일치하면 함포 발사 |
| **↑ / ↓**          | 함선 상하 이동 (미사일 회피)     |
| **ENTER** (일시정지 중) | 게임 재개                 |
| ⚙ (설정)             | 콜사인·언어·학년(Grade) 변경   |




### 출제 단어 (어휘 사전)

- 단어 데이터는 초등 필수어휘 권장 낱말목록을 기반으로 작성되었습니다.
- **POWER BEAM CODE**는 선택한 학년(또는 영어)의 **"속담·관용구"**에서 무작위로 출제됩니다.



### 전투 흐름

1. 화면에 등장하는 적 함선 위의 **단어**를 하단 콘솔에 입력하고 **ENTER**를 누릅니다.
2. 단어가 정확히 일치하면 함포가 발사되어 적이 격추됩니다. (동일 단어 적이 여러 척이면 모두 명중 대상)
3. 오타를 입력하면 POWER BEAM 충전이 **-10** 감소합니다.
4. 적 함선은 미사일·레이저를 발사합니다. 가까이 오면 콘솔에 경고가 표시되니 화살표 키로 회피하세요.



### POWER BEAM

- 적을 명중할 때마다 POWER BEAM 충전게이지가 **+10** 충전됩니다.
- 게이지가 **100%**가 되면 발사 코드 입력 모드로 전환됩니다.
- 콘솔에 표시된 **POWER BEAM CODE**(한글 속담·관용구 또는 영어 속담·관용어)를 정확히 입력하면 화면의 모든 적이 격추됩니다. (**+1000 MISSION PTS**)
- 코드 입력에 실패하면 POWER BEAM 충전팩이 폐기되고 일반 전투 모드로 돌아갑니다.



### 챌린지 클리어 & 게임 오버

- 각 챌린지에서 **챌린지 번호 × 10**척의 적을 격추하면 클리어합니다. (예: CHALLENGE 3 → 30척)
- 챌린지가 올라갈수록 동시에 등장하는 적 수가 늘어납니다. (최대 **CHALLENGE 15**)
- **ENERGY SHIELD**가 0이 되면 게임 오버입니다.



### 점수 계산


| 항목               | 점수                                        |
| ---------------- | ----------------------------------------- |
| 적 격추 1척          | +100 MISSION PTS                          |
| POWER BEAM 발사 1회 | +1000 MISSION PTS                         |
| 최종 점수            | MISSION PTS + (TRIGGERING SKILL × 도달 챌린지) |
