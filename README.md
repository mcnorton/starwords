# Starwords

우주 테마 타자 연습 게임 (STAR WORDS).

## 플레이

**[https://mcnorton.github.io/starwords/](https://mcnorton.github.io/starwords/)**

로컬에서 실행하려면 이 폴더를 정적 서버로 열면 됩니다.

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 으로 접속합니다.
